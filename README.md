# Decoy-State BB84 QKD Simulation

A practical decoy-state BB84 quantum key distribution simulation with channel effects, detector modeling, decoy-state parameter estimation, finite-key bounds, key-rate estimation, and plotting utilities.

## Requirements
- Python 3.10+
- numpy
- matplotlib

Install dependencies:
```bash
pip install numpy matplotlib
```

## Run the simulation
From the project directory:
```bash
python -m src.main
```

## Generate plots
```bash
python -m src.plotting
```

## Project structure
- `src/` : simulation modules and drivers
- `plots/` : generated figures
